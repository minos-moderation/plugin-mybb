# Minos — moderacja postów dla MyBB

Wtyczka do forum MyBB 1.8, która wysyła nowe posty do bramy Wergiliusza, a werdykt odebrany
podpisanym webhookiem stosuje w kolejce moderacji forum: bezpieczny post publikuje,
ocenzurowany publikuje z zamaskowanymi fragmentami, a zablokowany zatrzymuje lub usuwa — tak,
jak ustawi administrator. Część projektu Minos. Wtyczka jest w przygotowaniu; instrukcja
instalacji pojawi się tutaj razem z pierwszą wersją. Licencja: GPL-2.0 (plik `LICENSE`).
